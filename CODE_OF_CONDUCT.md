# Code of conduct

Quadra should be a friendly place to ask, suggest and contribute, for everyone.

**Please:** be kind and patient, assume good intent, welcome newcomers, and keep discussions
about the project.

**Not accepted:** harassment, insults, discriminatory jokes or language, personal attacks, and
publishing other people's private information.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and
block people who keep breaking them.

To report a problem, use GitHub's **Report content** option on the comment, or message
[@ahrmichelon](https://github.com/ahrmichelon) privately.

This code is based on the [Contributor Covenant](https://www.contributor-covenant.org/).
